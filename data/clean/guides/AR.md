# AR — Arkansas guide

Files (all `use`, 2022 revision): one document per grade/band or course.
- `AR_Grades_K-4_...` — K-4 in one doc. "At a Glance" tables have grade columns (Kindergarten, Grade 1 ... Grade 4): map each column cell to its grade. Knowledge and Skill Performance Expectations (KPEs/SPEs) carry codes like `C.1.K.1` / `H.3.2.4` (strand.standard.GRADE.number) — the grade is the third part (K, 1, 2, 3, 4).
- `AR_Grades_5-6_...` — Grade 5 and Grade 6 sections; codes like `G.3.5.5` (grade 5) / `G.3.6.2` (grade 6). Running headers say Grade 5 / Grade 6.
- `AR_Grade_7_...`, `AR_Grade_8_...` — single grades.
- `AR_Grades_7-8_Arkansas_History_...` — course "Arkansas History", grades 7-8 (course row).
- `AR_Grades_9-12_Arkansas_History_...` and HS course docs (African American History, Civics, Economics with Personal Finance, Psychology, Sociology, U.S. Government, U.S. History since 1929, World Geography, World History since 1450) — course rows, grades 9-12 unless stated.

Row clusters: K,1,2,3,4,5,6,7,8 (grade rows), plus course rows (7-8 Arkansas History; 9-12 courses).

Structure notes: every doc starts with "Course Focus and Content", "Integrating Standards", "Related Laws", the C3 inquiry dimensions page (Dimensions 1, 3, 4 numbered skills that "should be addressed throughout Grades K-4"): these numbered inquiry skills ARE standards shared by the doc's grades — label them standards with the doc grade range; the surrounding explanation is backup. The "K-12 Disciplinary Standards Overview" (C.1, E.1, G.1, H.1 statements) is shared by all grades of that doc: label it with the doc's grade range as standards. "Teacher Note:" blocks are examples. Asterisks (*) mark background-knowledge content (still standards).
